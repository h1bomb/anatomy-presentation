# Anatomy 深度解析 · 15章动态 B-roll 演示与视频渲染系统设计规范

- **日期**：2026-10-15
- **输入源**：`Anatomy深度解析_口播稿与文案包.md`（ch01–ch15，共15章）
- **核心技能依赖**：`/.agents/skills/anatomy`（`kit/iso-kit.mjs`, `examples/*`, `scripts/*`）
- **画布规格**：`1920 × 1080`（16:9 横屏），深色主题（Anatomy Dark Theme `#111110`），单章标准时长 `40.0 秒`，帧率 `30 fps`

---

## 1. 目标与成功标准

1. **视觉无边框融合**：将实时运转的 Anatomy 等轴测机械动画（SVG / WebGL 着色器 / 3D 实时重投影）与章节幻灯片排版融于同一张 `#111110` 深色工程画布中，彻底消除传统 PPT 贴图的割裂感。
2. **40 秒口播节奏同步**：每章 40 秒按口播文稿精确划分为 4 个时间节拍（Beat 1: `0–10s`, Beat 2: `10–20s`, Beat 3: `20–30s`, Beat 4: `30–40s`）。每个节拍触发：
   - 左侧幻灯片卡片与关键指标的弹簧渐进揭示（Staggered Reveal）；
   - 右侧/背景等轴测机器的特定物理状态切换（如慢动作、爆炸拆解、WebGL 点火、指针偏转、射线扫描、滚轮翻页）；
   - 顶部实时物理读数（Readout）与底部可开关口播同步字幕条（Subtitles HUD）的同步更新。
3. **双模交付（交互演播 + 确定性 MP4 导出）**：
   - 交付 `dist/broll-player.html`：可在浏览器全屏打开，支持自动连播、章节跳转、节拍快进、字幕显隐切换（`C` 键）；
   - 交付 `output/videos/ch01.mp4` ~ `ch15.mp4`：通过 Chrome DevTools Protocol (CDP) + `ffmpeg` 确定性帧渲染导出 15 段 1920×1080 40 秒高清 MP4 视频片段。

## 2. 视觉与排版系统（Editorial Technical Instrument 美学）

### 2.1 色彩与色调层级（对齐 `kit/iso.css` 深色规范）
- **背景层（Canvas Ground）**：`#111110` 主底色 + `rgba(255, 255, 255, 0.025)` 等轴测正交辅助网格（30°/45°） + 舞台中心径向微光晕 `radial-gradient(circle at 66% 52%, rgba(243,242,237,0.055), transparent 62%)`。
- **四级明暗（Four-Tone Shading）**：
  - `lo`：`#1b1b19`（底座、非活动节拍卡片、次要刻度）
  - `mid`：`#272724`（结构支架、边框、常规文字 `#9e9d95`）
  - `hi`：`#3a3a35`（主体零件、次标题 `#d6d5ce`）
  - `lit`：`#f3f2ed`（当前激活焦点、指针、核心金句与主数字）
  - **工程强调色（Accent）**：琥珀仪器光 `#e5a93c`（用于关键数据高亮、激光扫描线、慢动作/点火状态指示灯）与朱红警示色 `#e05a47`（用于反例打叉与穿插错误标注）。

### 2.2 1920×1080 空间分区
1. **顶部精密铭牌栏（Top Instrument Bar, `height: 76px`, `padding: 0 56px`）**：

   - 中：4 段式 40s 节拍进度尺（Beat 01–04 刻度与实时毫秒计时器 `00:00.0 / 00:40.0`）；
   - 右：与当前等轴测机器状态绑定的实时工程读数（Live Readout，等宽数字 `tabular-nums`）。
2. **中右等轴测主舞台（Isometric Stage, 占据画面右侧 62% 区域并向左侧自然延伸羽化）**：
   - 承载 `iso-kit.mjs` 构建的定制动态 SVG 机器，或无边框内嵌的官方深色示例机器；
   - 支持随时间轴节拍触发镜头推拉（`scale` / `translate` 平滑过渡，如 4× 局部放大审校视角）及机器内部动作。
3. **左侧渐进式幻灯片面板（Slide Narrative Stack, `width: 720px`, `left: 56px`, `top: 108px`, `bottom: 116px`）**：
   - 章节核心命题横幅（Chapter Thesis Banner）；
   - 4 张节拍卡片（Beat Cards）：随 `0s / 10s / 20s / 30s` 依次入场。每张卡片包含节拍时间码、核心提炼标题、精炼要点/数据对比芯片（Metric Chips）及微型等轴测图例符号；
   - 章节金句/结论铭牌（Key Takeaway Plate）：在第 4 节拍（`30s`）高亮锁定。
4. **底部口播同步字幕与控制栏（Teleprompter HUD, `bottom: 24px`, 可按 `C` 键或 URL 参数 `?subtitles=0` 隐藏）**：
   - 实时显示当前节拍对应的口播稿原句，已读字词高亮推进，方便直接对齐配音轨或作为带字幕成片使用。

## 4. 确定性视频导出管线 (`scripts/export-mp4.mjs`)

1. **渲染原理**：
   - 启动无头 Chrome（`--headless=new --window-size=1920,1080 --hide-scrollbars --enable-webgl --ignore-gpu-blocklist`）加载 `dist/broll-player.html?export=1`。
   - 对每个目标章节 `ch`（`1..15`），以 `fps = 30`（每章 `40s × 30 = 1200` 帧，或支持 `--fps` 与 `--chapters` 参数按需配置）调用页面暴露的 `await window.__renderFrame(chIndex, timeSec)`。
   - 使用 CDP `Page.captureScreenshot({ format: "jpeg", quality: 92 })` 将二进制帧直接通过 `stdio: ["pipe", ...]` 写入 `ffmpeg` 进程：
     ```bash
     ffmpeg -y -f image2pipe -vcodec mjpeg -r 30 -i - -c:v libx264 -pix_fmt yuv420p -preset fast -crf 18 output/videos/chXX.mp4
     ```
2. **优势**：
   - 不依赖系统屏幕录制权限，不受 CPU 瞬时负载影响，每一帧的时间戳 `timeSec = frame / fps` 100% 精确，生成的 MP4 可直接拖入剪辑轨与口播音频对齐。
